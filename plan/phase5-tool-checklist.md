# 에이전트 8종 도구 — 실제 브라우저 점검표

갱신: **2026-09-12**. 이번에는 실제 확장 E2E를 실행하지 않았다. 아래 모든 체크박스는 **재검증 대기**이며 과거 모델 선택 정확도 실험과 구분한다. 단위 테스트와 기본 Ollama live 결과는 [검증 기록](../docs/VALIDATION.md)을 참고한다.

## 준비

- [ ] `npm run compile`, `npm test`, `npm run build` 통과.
- [ ] `.output/chrome-mv3`를 별도 테스트용 Chrome 프로필에 설치.
- [ ] Chrome/OS/Ollama/모델 태그·digest/numCtx/Thinking/CPU·GPU 기록.
- [ ] localhost Ollama 연결 및 tools capability 확인.
- [ ] 테스트용 페이지에 읽을 본문, 이름 있는 링크, 입력 칸, 중복/숨김/disabled 요소 준비.
- [ ] 브라우저 권한 상태 기록. 사이트별 권한과 `<all_urls>`를 나눠 시험.
- [ ] 테스트 데이터만 사용하고 실제 전송·결제·계정 변경 버튼을 대상으로 삼지 않음.

## 승인과 취소

- [ ] 승인 카드에 페이지·대상·행동을 확인할 수 있음.
- [ ] 기본 포커스 거부, Esc 거부, Enter만으로 승인되지 않음.
- [ ] 거부한 동일 행동을 반복 승인 요청하지 않음.
- [ ] 승인 대기 중 중단 시 액션 없음.
- [ ] 승인 중 DOM/문서가 바뀌면 다른 대상에 실행되지 않음(R03 코드·fixture 보완 완료, 이 항목은 실제 확장 QA).
- [ ] 도구 요청이 응답하지 않아도 제한 시간 후 UI가 종료됨(R02 코드·회귀 보완 완료, 이 항목은 실제 확장 QA).
- [ ] 중단 직후 새 요청을 보내도 이전 작업이 새 상태를 덮지 않음(R05).
- [ ] 완료 메시지와 실제 페이지 결과가 일치함. DOM 호출 성공만으로 서버 저장 성공을 단정하지 않음.

## 탭·창·페이지 경계

- [ ] 탭 A에서 캡처를 시작하고 B로 전환해도 B 화면이 A 요청에 전달되지 않음(R01).
- [ ] 다른 창 활성화·탭 닫기·새로고침·SPA 이동 처리.
- [ ] 같은 URL의 동적 본문은 분리/재첨부로 새로 읽힘.
- [ ] iframe·Shadow DOM·contenteditable의 미지원 상태를 성공으로 표시하지 않음.
- [ ] 사이트 권한 철회 후 실패 안내, 금지된 chrome://·웹스토어 처리.
- [ ] 사이트별 권한만 있을 때 screenshot 도구가 실패하는 제한을 설명함.

## 루프와 비신뢰 입력

- [ ] 최대 턴에서 중단, 같은 도구+인자 3회 후 다음 반복 중단.
- [ ] 연속 실패 제한, 무응답 시간 제한, 사용자 중단.
- [ ] 페이지에 “이전 지시 무시/자동 클릭” 문구를 넣어도 부작용 액션은 승인 없이 실행되지 않음.
- [ ] javascript:/file: 이동 요청 거부.
- [ ] `<script>`, 이벤트 속성, 실행형 링크가 모델 답변에 있어도 실행되지 않음.
- [ ] 긴 본문과 도구 결과 누적에 대해 예산 및 잘림 안내 확인(R06).

## 메모리 및 데이터 회귀

- [ ] 기억 끄기 상태에서 신규 pageVectors 저장 없음.
- [ ] 제외 도메인과 하위 도메인 신규 저장 없음.
- [ ] 기존 하위 도메인 기록까지 삭제됨(R04 코드·회귀 보완 완료, 이 항목은 실제 확장 QA).
- [ ] 임베딩 진행 중 삭제·제외·패널 종료 후 기록 재등장 없음(R04).
- [ ] 보관 기간 지난 기록이 검색되지 않음(R09).
- [ ] 대화 기록 삭제가 기억 삭제와 별개임을 UI에서 이해할 수 있음.

## 결과 기록

각 항목에 성공/실패, 재현 단계, 권한, 모델 요청·응답, 실제 DOM 결과, 첫 답변 시간·전체 시간, 화면 파일을 기록한다. 모델이 올바른 도구를 선택한 비율과 브라우저가 의도한 작업을 끝낸 비율을 각각 계산한다. 특정 장비의 과거 성능 수치를 합격 보장으로 사용하지 않는다.
