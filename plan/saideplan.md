# sAIde — 현재 제품 계획

갱신: **2026-09-12 · 버전 0.1.0**. 2026-08의 최초 계획을 현재 소스와 검증 범위에 맞춰 갱신했다. 당시 측정·설계 변경의 원문은 Git 이력을 참고한다. 사용자 설치 절차는 [README](../README.md)가 기준이다.

## 1. 제품 목적

sAIde(사이드)는 브라우저 옆에서 페이지 이해와 작업을 돕는 Ollama 기반 Chrome 확장이다. 기본 모델 요청은 localhost로 전달한다. 원격 endpoint 입력을 차단하지 않으므로 로컬 전용이 강제된다는 표현은 사용하지 않는다.

브랜드 표기는 **sAIde**, 국문 **사이드**, 태그라인 **옆에서 돕는 AI**다. 색상·로고 원본은 [브랜드 시트](../brand/saide-brand-sheet.html)와 `src/lib/brand/tokens.css`를 따른다.

## 2. 현재 구현 범위

| 단계 | 현재 코드 | 이번 검증과 잔여 |
|---|---|---|
| 기반 | WXT MV3, 사이드패널, 설정, Ollama health | 타입/빌드 통과, 실서버 연결 확인 |
| 채팅 | 스트리밍·저장·추론 표시·중단·재생성·Markdown | 단위 통과, 탭 전환 경합 보완 필요 |
| 페이지 | Readability·innerText·자막·본문 예산·요약·번역 | 사이트별 실제 E2E 재검증 필요 |
| 멀티모달 | 현재 보이는 화면 첨부·설명 | 캡처 대상 검증과 capability gate 필요 |
| 프리셋 | 슬래시·선택 텍스트·사용자 프리셋 | 충돌 UX 및 저장 일관성 보완 |
| 에이전트 | 8종 도구, 클릭/입력/이동 승인, 반복 제한 | 실실행 취소·대상 고정·DOM 호환성 보완 |
| 기억 | 선택 활성화, 읽힌 페이지 임베딩, 명시 검색 | 삭제 경합·하위 도메인 삭제·만료 처리 보완 |
| 마감 | ko/en 카탈로그·테마·성능 기록·브랜드 자산 | 설정 언어 동기화, 접근성·배포 관문 미완료 |

여기서 구현됨은 코드 존재를 뜻한다. 전체 브라우저 기능·모델 정확도·스토어 출시 검증 완료를 뜻하지 않는다.

## 3. 현재 기본값과 제약

| 항목 | 현재 기본값 |
|---|---|
| 대화 / 임베딩 모델 | `gemma4:e2b` / `bge-m3` |
| 모델 문맥 / 본문 예산 | 4,096 / 2,000 토큰 |
| Thinking / 상주 | 에이전트에서만 / 10분 |
| 에이전트 | 기능 켜짐, 입력창에서 명시 선택, 최대 8턴 |
| 모델 무응답 제한 | 30초 |
| 기억 | 꺼짐, 활성화 시 30일 보관 |
| 언어 / 테마 | 한국어 / 시스템 |

과거 21.5초 콜드 로드, 131 tok/s 프리필, 21 tok/s 생성 수치는 특정 CPU 실측이며 다른 장비의 요구사항이나 보장값이 아니다. 모델의 최대 컨텍스트와 애플리케이션의 실제 기본 컨텍스트를 혼동하지 않는다.

기억은 모든 방문 기록이 아닌 사용자가 패널에 읽힌 본문 대상이다. 오프라인 사용은 사전 설치 모델·이미 읽을 수 있는 데이터 범위다. 네트워크가 필요한 페이지·자막·모델 다운로드까지 오프라인으로 제공하지 않는다.

## 4. 권한과 데이터 원칙

- 설치 시 고정 호스트는 localhost/127.0.0.1:11434.
- 일반 페이지 읽기와 에이전트 시작은 대상 사이트 권한 요청.
- 캡처는 구현상 `<all_urls>` 요청. 에이전트 실행 중에는 새 권한을 요청하지 못하므로 캡처 도구에 필요한 권한이 없으면 실패할 수 있음.
- 클릭·입력·이동은 매번 사용자 승인. 자동 승인 없음.
- 설정·프리셋은 chrome.storage.local, 대화·기억은 IndexedDB.
- 저장된 기록은 앱 수준에서 암호화하지 않음. 삭제·제외·만료 보장은 개선 과제.

## 6. 이번 기준 상태

단위 299개·타입 검사·Chrome 프로덕션 빌드와 Ollama 기본 live 4개 통과. 문서용 UI 예시 캡처를 제공했다. 실제 확장 설치·권한·도구 8종의 브라우저 E2E 및 전체 모델 정확도 실험은 재검증하지 않았다. 웹스토어 등록·공개 배포도 수행하지 않았다.
