밝은 배경 — AI는 바이올렛

어두운 배경 — AI는 앰버

아이콘

왼쪽은 페이지, 오른쪽 기둥은 사이드패널. 그 안의 점 하나가 AI입니다. 툴바에서 16px로 줄어드는 것을 전제로 설계했습니다.

48px 이상은 페이지 선 3줄 + 4각 스파크, 32px 이하는 선 2줄 + 원형 점으로 자동 교체합니다. 스파크는 작은 크기에서 뭉개지므로 단순형을 별도 파일로 관리합니다.

컬러

바이올렛은 AI를, 앰버는 "내 기기에서 도는 연산의 온기"를 맡습니다.

Violet — 주색#5B4BD6 → #7C6BF0

아이콘 배경, 워드마크의 AI(밝은 배경), 주요 버튼. 흰 배경 대비 5.8:1로 본문 텍스트에도 사용 가능.

Amber — 강조색#F5A524

사이드패널 기둥, 어두운 배경의 AI, 생성 중 표시. 흰 배경 위 텍스트로 사용 금지 — 대비 1.8:1.

Ink — 먹색#14121C

본문, 다크모드 배경, 아이콘 내부의 점.

Paper / Slate#FAFAF8 · #6B6880 · #E7E5EE

배경, 보조 텍스트, 구분선.

타이포그래피

영문 · 숫자Inter — 워드마크 800 / 600, UI 400~600. 대체: -apple-system, Segoe UI
국문Pretendard — 한글 자소가 Inter와 폭이 맞아 혼용 시 어긋나지 않습니다.
코드ui-monospace, SF Mono, Menlo

배포용 로고의 폰트는 아웃라인(패스)으로 변환돼 있습니다(2026-08-20). saide-wordmark.svg, saide-wordmark-dark.svg, saide-lockup.svg의 워드마크는 폰트 없이도 같은 자형으로 렌더됩니다. 락업의 한글 태그라인만 라이브 텍스트로 남아 있어 Pretendard가 없는 환경에서는 자형이 달라집니다.

사용 규칙

OAI 두 글자만 색·굵기로 강조합니다. 강조점은 언제나 하나입니다.
O국문 표기는 "사이드"로 고정합니다. "에이드"는 음료를 먼저 연상시킵니다.
O로고 주변 여백은 아이콘 높이의 1/2 이상 확보합니다.
Xsaide, SAIDE, Saide 등으로 임의 표기하지 않습니다. 소문자 강제 환경(도메인·저장소·패키지명)에서만 saide를 허용합니다.
X워드마크에 그림자·외곽선·그라디언트 텍스트를 넣지 않습니다.
X앰버를 밝은 배경의 본문·링크 색으로 쓰지 않습니다.
